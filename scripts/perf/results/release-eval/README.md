# Release-eval results

Outputs of `scripts/perf/release-eval.sh` land here as
`<version>/<hostid>/`. See [../../RELEASE-EVAL.md](../../RELEASE-EVAL.md) for
the layout, how to commit this tree, and the no-warranty disclaimer.

Keep only the per-host result directories (JSON, `report.md`, optional
baselines). Do not commit a run directory, podman store, or downloaded
archives.
