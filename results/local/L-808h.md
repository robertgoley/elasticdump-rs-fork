# L-808h: skip the `image` job on Dependabot PRs (2026-11-01)

User-requested fix-up. Dependabot PRs get no repository secrets, so the `image` job's dhi.io
login (the two dhi.io repository secrets) failed with "secrets are not set" on every Dependabot PR.

Change (`.github/workflows/security.yml`): a job-level
`if: github.event_name != 'pull_request' || github.event.pull_request.user.login != 'dependabot[bot]'`
on `image`. It keys on the PR author, not `github.actor`, so a human re-run of a Dependabot PR is
skipped too. A skipped job shows as "skipped", which passes required checks.

Unchanged on purpose:
- The hard failure (`::error::` + exit 1) when the secrets are missing stays for pushes to
  main/rewrite, schedule, dispatch and human PRs.
- `publishers` and `sbom-diff` have no `needs: image` and use no secrets. `publishers` runs only on
  schedule/dispatch, so it never runs on a PR anyway. `sbom-diff` is the SBOM review gate for
  dependency changes, so it should keep running on Dependabot PRs. Neither needed a change.
- No repository secrets or settings touched; the user adds the two dhi.io secrets themselves.

Check: actionlint 1.x on security.yml: clean.

Found, not changed (RESUME open item): `dtolnay/rust-toolchain` is pinned to the 1.85.1 branch
SHA (ccc8c1f), so the `toolchain:` input is ignored and "nightly" jobs get 1.85.1.
